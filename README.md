# 拼图助手

自动识别白色拼图验证码并完成拖动。

## 工作原理

1. 框选验证码区域（仅首次）
2. 浏览器扩展检测到目标网址 → 自动启动程序
3. 程序截屏 → 识别滑块和缺口 → 模拟拖动 → 退出

## 环境要求

- Windows 10/11
- Python 3.10+（源码运行时需要；打包成 exe 后不需要）
- Chrome 或 Edge 浏览器

## 安装

### 1. 安装 Python 依赖

```
pip install -r requirements.txt
```

### 2. 安装浏览器扩展

1. 打开 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 开启「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选择解压目录中的 `extension` 文件夹

### 3. 配置扩展

1. 点击浏览器工具栏的拼图助手图标
2. 输入验证码页面的网址关键词（如 `example.com/verify`）
3. 点保存

### 4.初次启动

1. 关闭浏览器并重新打开
2. 打开要登录的网址，此时会提示“想要打开程序”，点击允许
3. 等待程序界面出现后，按F8截图拼图区域（仅初次使用需要截图，以后都不用了）

## 快捷键

| 按键 | 功能 |
|---|---|
| F8 | 框选验证区域（仅首次） |
| F9 | 一键识别+拖动 |
| F2 | 取消操作 |

## 常见问题

**Q: 浏览器没弹出「打开外部应用」提示？**
检查扩展是否已加载，以及目标网址关键词是否匹配当前页面 URL。

**Q: 程序启动了但没拖动？**
可能是选区已过期（页面位置变了）。重新按 F8 框选。

**Q: 拖动方向反了或距离不对？**
程序已自动修正，如仍有问题请保存诊断图反馈。
