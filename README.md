# 拼图助手

自动识别白色拼图验证码并完成拖动。

## 工作原理

1. 框选验证码区域（仅首次）
2. 浏览器扩展检测到目标网址 → 自动启动程序
3. 程序截屏 → 识别滑块和缺口 → 模拟拖动 → 退出

所有图像识别都在本机完成，不联网、不上传任何数据。

## 环境要求

- Windows 10 / 11
- Chrome 或 Edge 浏览器

## 获取程序

发布包见右侧 **Releases**，下载后解压即可使用，无需安装 Python。

## 安装

1. 解压发布包，运行其中的 `Setup.exe`。
2. 阅读安装说明并同意，选择 Chrome、Edge 或两者。
3. 确认目标网址（默认填入需要登录的验证码页面地址，可以修改）。
4. 为“框选识别区域”“识别并执行”“取消操作”分别选择互不重复的 F1–F12 快捷键。
5. 点击安装。安装过程会自动完成协议注册和浏览器扩展加载，**期间请保持桌面解锁，不要操作鼠标或键盘**。

详细说明见 [`windows/extension/README.md`](windows/extension/README.md)。

## 初次使用

1. 关闭浏览器并重新打开，让扩展生效。
2. 打开要登录的网址，浏览器会提示“想要打开程序”，点击允许。
3. 程序界面出现后，按安装时设置的“框选识别区域”快捷键（默认 F8），框住完整的验证码图片和底部的拖动滑轨。
4. 这一步只有首次需要，之后进入该页面直接按 F9 即可。

## 快捷键

| 按键（默认） | 功能 |
|---|---|
| F8 | 框选验证区域（仅首次） |
| F9 | 一键识别 + 拖动 |
| F2 | 取消操作 |

三个快捷键均可在安装时从 F1–F12 中自定义。

## 常见问题

**浏览器没有弹出「打开外部应用」的提示？**
确认扩展已加载，以及安装时填写的网址关键词确实出现在当前页面地址中。

**程序启动了但没有拖动？**
多半是选区已过期（页面布局变了）。重新按 F8 框选一次。

**提示“检测到多个可能目标，请缩小选区”？**
框选范围里出现了不止一个验证框，或包含了页面其他白色区域。重新按 F8，只框住一个验证框和它的滑轨。

**提示“超时，重按……”？**
识别结果已超过 20 秒，页面验证码可能已刷新。重新按 F9 即可。

**提示“Windows 拒绝鼠标输入”？**
请确认浏览器和本程序都以普通权限运行，没有以管理员身份打开其中之一。

**拖动总是差几个像素？**
程序在每次拖动后会按缺口剩余白区自动微调，通常无需干预。

## 卸载

运行安装目录中的 `Uninstall.exe`，或在 Windows 设置的“已安装的应用”里卸载。卸载会移除本程序、扩展文件和协议注册。
