# 拼图助手 · Windows Monitor 版

登录页出现白色拼图验证码时，帮你自动完成拖动。这一版**不需要浏览器扩展、不注册任何协议**：装完有一个程序常驻系统托盘，随 Windows 登录启动，检测到你用选定的浏览器进入目标网址就开始工作。图片识别全部在本机进行，不联网、不上传任何数据，也不读取浏览器里的登录信息。

## 安装

1. 解压发布包，运行其中的 `Setup.exe`。
2. 阅读安装说明并同意。这一版会常驻后台并随登录启动，说明里会写清楚；不同意可以直接退出，不会复制任何文件。
3. 选择 Chrome、Edge 或两者都选。程序只在你用选定的浏览器打开目标网址时工作。
4. 目标网址这一页：「上财」已经默认勾选并填好网址，确认无误直接下一步即可；要监测别的页面就取消勾选后自己填完整网址。
5. 选三个快捷键：框选识别区域、识别并执行、取消操作（默认 F8 / F9 / F2，三者互不重复）。
6. 点安装。装完程序会先讲清楚识别区域怎么框，确认后启动后台监听，并用你选的浏览器打开目标网址。

## 使用

1. 用选定的浏览器打开目标网址，进到出现验证码的那一页。
2. 第一次用：按 F8 框住完整的验证码图片**和它底部的拖动滑轨**。这一步只做一次。
3. 之后每次：进入目标页会自动截图定位。默认**不弹操作窗口**，直接按 F9 完成识别和拖动，中途想停按 F2。
4. 想看到窗口、或者想核对它找到的位置对不对：双击托盘图标打开「设置…」，勾上「检测到目标页面时自动弹出操作窗口」。勾选后窗口会压在浏览器上面保持可见，你仍然能正常在网页里输入；离开目标页它自己收起。

选区保存的是屏幕绝对位置。换了显示器、改了分辨率或页面布局变了，重新框选一次即可。

## 设置

双击托盘图标（或右键菜单里的「设置…」）就能改这三项，**不需要先把识别程序唤起来**：

- **拖动速度**：100~3000 px/s。感觉拖过头、或者页面跟不上时调慢一点。
- **快捷键**：三个动作都能在 F1~F12 里换。
- **自动弹出操作窗口**：取消勾选即完全静默，只用键盘。

操作窗口里也有同样的「设置」页，两边改的是同一份配置。目标网址不在这里改——要换监测的页面，重新运行一次 `Setup.exe` 就行。

托盘菜单里还有一项「暂停 / 启用」：暂停后后台监听仍在，但不再自动开始识别，几个快捷键也不会触发任何动作；再点一次「启用」就恢复。

## 常见问题

| 提示 | 怎么处理 |
|---|---|
| 未找到可靠的白色拼图缺口和滑轨 | 重新框选，确保验证码图片和底部滑轨都在选区里 |
| 检测到多个可能目标；请缩小选区 | 选区里框进了不止一个验证框 |
| 起终点不在同一窗口 | 选区跨到了别的窗口，重新只框住验证码区域 |
| 目标超出滑轨，已取消操作 | 重新框选；滑轨很短时尽量只框验证码区域 |
| 进了目标网址却没反应 | 看托盘图标在不在；确认用的是安装时选的那个浏览器；再确认托盘菜单不是「暂停」状态 |
| F2、F8 或 F9 按了没反应或被别的程序占用 | 双击托盘图标打开「设置…」换一组不冲突的快捷键 |
| 看不到任何窗口 | 正常：这一版默认完全静默，按 F8 框选一次，之后按 F9 识别并拖动；想恢复弹窗就在「设置…」里勾上自动弹出 |
| 每次都差几像素拖不过 | 把拖动速度调慢；仍不行就重新框选，让选区只包含验证码 |
| 换了显示器或分辨率后不灵 | 选区记的是屏幕绝对坐标，重新框选一次 |

## 卸载

运行安装目录里的 `Uninstall.exe`，或在 Windows 设置的「已安装的应用」中卸载。会停掉后台监听、删掉登录启动项和安装目录，不会动浏览器自身的书签、历史和设置。

## 已知限制

- 选区保存的是屏幕绝对位置，换显示器、改分辨率或页面布局变化后需要重新框选一次。
- 后台监听常驻期间会占用你设定的三个快捷键，和其他程序冲突时在「设置…」里换一组。
- 个别网站把拼图块位置量化得比鼠标移动还粗，最终落点会有几像素偏差，可以把拖动速度调慢再试。
- 页面重绘明显慢于约 0.25 秒时，落点的细验证可能提前收手，这种情况请重新框选，让选区只包含验证码图片和它底部的滑轨。
