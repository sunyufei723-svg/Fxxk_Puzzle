# Windows Extension 版使用说明

Extension 版通过浏览器扩展检测目标网址，再自动启动本地拼图程序。整个安装流程由 `Setup.exe` 完成，你不需要手工注册协议、配置网址或加载扩展。

所有图像识别都在本机完成，不联网、不上传任何数据。

## 安装

1. 解压完整的发布包，运行其中的 `Setup.exe`。
2. 阅读安装说明并明确同意，然后选择 Chrome、Edge 或两者。
3. 在目标网址页面勾选需要登录的站点，文本框会自动填入对应地址；也可以手工修改成你自己的验证码页面网址。
4. 为“框选识别区域”“识别并执行”“取消操作”分别选择互不重复的 F1–F12 快捷键。
5. 点击安装。安装程序会把应用放到 `%LOCALAPPDATA%\Programs\FxxkPuzzleExtension`，为当前用户注册启动协议，然后依次打开所选浏览器并完成扩展加载。浏览器操作优先使用 Windows 无障碍接口，必要时才回退到安装包内置的界面位置。
6. **自动加载期间请保持桌面解锁，不要操作鼠标或键盘。** 如果安装程序无法确认你浏览器上的操作目标，它会停下来给出提示，不会继续盲目点击。
7. 安装完成后，安装程序会先说明识别区域怎么配置；确认后才会自动打开目标网址。

## 首次使用

1. 关闭浏览器并重新打开，让扩展生效。
2. 打开要登录的网址，浏览器会提示“想要打开程序”，点击允许。
3. 网页出现拼图验证码时，按安装时设置的“框选识别区域”快捷键，框住完整的验证码图片**和它底部的拖动滑轨**。
4. 框选只需做一次，之后每次按“识别并执行”快捷键即可。

选区保存的是屏幕绝对位置。如果页面布局发生变化或换了显示器，重新框选一次。

## 卸载

运行安装目录中的 `Uninstall.exe`，或在 Windows 设置的“已安装的应用”中卸载。卸载会移除本程序、扩展文件和协议注册，不会影响浏览器自身的书签与设置。
