# 拼图助手 · Windows Extension 版

登录页出现白色拼图验证码时，帮你自动完成拖动。图片识别全部在本机进行，不联网、不上传任何数据。

## 安装

1. 解压发布包，运行其中的 `Setup.exe`。
2. 阅读安装说明并同意，选择 Chrome、Edge 或两者都装。
3. 目标网址这一页：「上财」已经默认勾选并填好网址，确认无误直接下一步即可；要监测别的页面就取消勾选后自己填。
4. 选三个快捷键：框选识别区域、识别并执行、取消操作（默认 F8 / F9 / F2，三者互不重复）。
5. 点安装。程序会装到 `%LOCALAPPDATA%\Programs\FxxkPuzzleExtension`，注册启动协议，然后自动打开浏览器的扩展管理页完成加载。
   **这期间请保持桌面解锁，不要动鼠标和键盘。** 如果向导认不出该点哪里，它会停下来给出提示，不会盲目点击。
6. 装完后关掉浏览器再重新打开，让扩展生效。

## 使用

1. 打开要登录的网址，浏览器会问「是否打开拼图助手」，点允许。
2. 第一次用：按 F8 框住完整的验证码图片**和它底部的拖动滑轨**。这一步只做一次。
3. 之后每次：程序一启动就会自己截图并定位，窗口里画出它找到的缺口和拖动箭头，不用再点「识别」。
4. 箭头确实指向缺口时，按 F9 完成拖动；也可以直接点「执行」。没定位到就点「识别」重来一次。
5. 中途想停：按 F2 或点「取消」，鼠标会立刻抬起。

选区保存的是屏幕绝对位置。换了显示器、改了分辨率或页面布局变了，重新框选一次即可。

程序只会读取启动它的那个浏览器窗口的当前网址；确认进入目标网址之后，切到其他标签、跳转离开或关闭那个窗口，程序会自动退出。

## 设置

- **拖动速度**：100~3000 px/s。感觉拖过头、或者页面跟不上时调慢一点。
- **快捷键**：三个动作都能在 F1~F12 里换，改完立即生效并自动保存，重启后仍然有效。
- **保存诊断**：在「日志」页，把当前截图存成安装目录下的 `debug_last.png`，方便回看这一次到底识别到了什么。

## 常见问题

| 提示 | 怎么处理 |
|---|---|
| 未找到可靠的白色拼图缺口和滑轨 | 重新框选，确保验证码图片和底部滑轨都在选区里 |
| 检测到多个可能目标；请缩小选区 | 选区里框进了不止一个验证框 |
| 起终点不在同一窗口 | 选区跨到了别的窗口，重新只框住验证码区域 |
| 目标超出滑轨，已取消操作 | 重新框选；滑轨很短时尽量只框验证码区域 |
| F2、F8 或 F9 已被其他程序占用 | 在「设置」页换一组不冲突的快捷键 |
| 超时，重按 F9 | 页面验证码已刷新，重按 F9 重新识别 |
| 检测到你仍按着鼠标左键 | 松开左键，再重新识别 |
| 每次都差几像素拖不过 | 把拖动速度调慢；仍不行就重新框选，让选区只包含验证码 |
| 装完扩展没反应 | 完全关掉浏览器再打开；仍不行就重跑一次 `Setup.exe` |

## 卸载

运行安装目录里的 `Uninstall.exe`，或在 Windows 设置的「已安装的应用」中卸载。只会删除本程序、扩展文件和协议注册，不会动浏览器自身的书签、历史和设置。
